# Каталог исключений российских сервисов

Версия `2026-10-10.1`, экспериментальная. Источник для приложения и расширения — `Shared/Resources/ServiceBypassCatalog.json`. Восемь групп, 99 исходных записей, 96 маршрутов после удаления вложенных диапазонов.

## Что проверено

10 октября 2026 года проверены DNS A/AAAA 55 доменов Ozon и пяти новых групп через публичный resolver Cloudflare. Адреса сопоставлены с [RIPE RDAP](https://rdap.db.ripe.net/) и [RIPEstat network-info](https://stat.ripe.net/docs/data-api/api-endpoints/network-info). Наблюдения сохранены в [DNS-снимке](SERVICE-BYPASS-DNS-2026-10-10.json); `source` каждой записи каталога ведёт к её сетевому реестру. Старые записи Wildberries и Яндекса сохранены из проверки 6 октября, повторная проверка этих групп не проводилась.

DNS наблюдался с Mac, не с iPhone и не обязательно из сети пользователя. Это основания для каталога, а не доказательство полного покрытия нативного приложения или прямого маршрута на телефоне. Для новых доменов AAAA-адресов в этой выборке не было; прежние IPv6-правила WB и Яндекса сохранены.

| Группа | Записей | Покрытие и основание |
|---|---:|---|
| Ozon | 13 | Три прежние сети `185.73.193/194/195.0/24`; восемь точечных адресов региональных изображений; две сети `ECOM-BANK` для `finance.ozon.ru` |
| Wildberries | 10 | Прежние сети сайта, API, static-basket и basket; один IPv6 host snapshot |
| Яндекс | 15 | Прежние сети Поиска, ID, Карт, Go, Почты, Диска и статики |
| MAX | 24 | Точечные адреса сайта, веб-клиента, API `oneme.ru`, WebSocket, звонков и медиа |
| СДЭК | 4 | Точечные адреса сайта, личного кабинета, API и страницы проверки Servicepipe |
| Госуслуги | 22 | Точечные адреса портала, ЕСИА, личного кабинета, Госключа и статики `gu-st.ru` |
| mos.ru | 10 | Точечные адреса портала, `login`, `oauth`, `my` и `pgu` |
| Мосэнергосбыт | 1 | Собственная сеть `MOSENERGOSBYT-NET` `195.82.140.0/24`: сайт, `my` и `lkkbyt` |

Для собственной сети выбирается узкий зарегистрированный и анонсируемый диапазон. Для общих CDN, защиты от DDoS, хостинга и операторских сетей добавлены только наблюдаемые `/32`, без расширения до сети провайдера. Даже точечный IP может обслуживать чужие домены — поэтому включение исключений остаётся явным действием пользователя.

Для MAX назначения `api.oneme.ru`, `calls.okcdn.ru`, `api.mycdn.me`, `st.mycdn.me` и `api.ok.ru` найдены в публичных файлах [веб-клиента](https://web.max.ru/) (`Bn2ajrGW.js`, `0.DhOwlT5a.js` на дату проверки). Тестовые среды `calls-test` не добавлялись. Общие адреса медиасервисов могут также вывести из VPN часть трафика Одноклассников; весь VK/OK ASN не исключается. Адреса ICE/TURN для конкретного звонка могут выдаваться динамически — звонки на iPhone требуют отдельной проверки.

Сайт СДЭК отдаёт проверку со скриптами `servicepipe.tech`, поэтому её наблюдаемый адрес включён в ту же группу. Сам факт такой страницы не доказывает блокировку VPN. HTML Госуслуг подтверждает использование `gu-st.ru`. Главная страница mos.ru, вход и кабинет имеют разные адреса и включены отдельно.

## Проблема Ozon

Пользователь сообщил, что плохо работает приложение в целом. В сохранённых логах iPhone за 10 октября прежний каталог `2026-10-06.1` применялся с группами `ozon,wildberries,yandex` и 25 маршрутами. Это подтверждает применение настройки, но не маршрут каждого запроса Ozon.

В прежние три подсети **не попадали** наблюдаемые адреса:

| Назначение | Добавлено |
|---|---|
| `ir-3.ozone.ru` | `5.101.71.73/32` |
| `ir-4.ozone.ru` | `185.40.155.13/32` |
| `ir-5.ozone.ru` | `212.164.51.50/32`, `212.164.51.51/32` |
| `ir-9.ozone.ru` | `85.173.175.100/32`, `85.173.175.101/32` |
| `ir-10.ozone.ru` | `176.208.118.244/32`, `176.208.118.245/32` |
| `finance.ozon.ru` | `194.9.211.0/24`, `31.130.143.0/24` — зарегистрированные сети ECOM-BANK |

Основные `api.ozon.ru`, `xapi.ozon.ru`, `m.ozon.ru`, `id.ozon.ru`, `st.ozone.ru` и `v.ozone.ru` в этой выборке уже попадали в старые правила. Новый каталог устраняет найденный пробел CDN/финансовой части, но **не подтверждён как исправление пользовательской проблемы**.

10 октября в 14:45–14:54 МСК новый каталог проверен на iPhone 16 Pro, iOS 26.6.2, в мобильной сети; Ozon 19.31.0 (1028). Лог подтверждает применение всех восьми групп и 96 маршрутов. Первый запуск Ozon с VPN завершился ошибкой «Похоже, нет соединения». После отключения VPN и обновления главная с изображениями загрузилась. После повторного подключения VPN поиск вернул названия и цены, а изображения появились с задержкой, ещё при активном VPN. Это смешанный результат: Ozon работает нестабильно, корневая причина не установлена. Сетевой захват для проверки фактических назначений/маршрутов недоступен без административного доступа к `tcpdump`. Подробности и границы проверки — в [отчёте устройства](DEVICE-TESTING.md).

Отличие DNS через VPN, другой региональный CDN и особенности выбора маршрута iOS остаются гипотезами. `enforceRoutes` не менялся. Расширять сети без наблюдения фактических соединений оснований нет.

## Управление выбором

«Исключить все» выбирает все восемь групп текущего списка одним сохранением; выключение очищает выбор. «Выбрать сервисы» раскрывает отдельные переключатели и показывает число выбранных. При частичном выборе общий переключатель выключен, а отдельные выбранные сервисы продолжают работать напрямую. Раскрыть список можно и при подключённом VPN; изменение выбора по-прежнему доступно только после отключения.

При обновлении сохранённый набор не расширяется автоматически: прежние три выбранные группы остаются тремя. Новые группы по умолчанию выключены. Это выбор перечисленных сервисов, а не обход VPN для всех российских адресов. Отдельного сохраняемого флага «все будущие сервисы» нет.

## Следующие кандидаты

Это приоритеты для дальнейшей проверки, а не утверждение, что сервисы обязательно блокируют любой VPN. Они пока не добавлены в каталог.

| Приоритет | Кандидаты | Что нужно проверить до добавления |
|---|---|---|
| Высокий | Используемые банки: Сбер, Т-Банк, ВТБ, Альфа-Банк | Мобильный вход, подтверждения и платёжные шлюзы; отдельные группы, не общие сети защиты |
| Высокий | [ФНС](https://www.nalog.gov.ru/rn77/), «Мой налог» | Личный кабинет `lkfl2.nalog.ru` и другие отдельные сервисы, вход через ЕСИА; исключение Госуслуг не покрывает ФНС |
| Средний | [Почта России](https://www.pochta.ru/), [РЖД](https://ticket.rzd.ru/) | Отслеживание/вход и поиск билетов без оформления; точечные адреса в операторских сетях |
| Средний | [2ГИС](https://2gis.ru/), [Авито](https://www.avito.ru/) | Карты, поиск, изображения, вход; у 2ГИС отдельно API/тайлы/вход, у Авито сайт и мобильный API |

Для этих пяти веб-сервисов проверены базовые DNS-адреса; у ФНС и 2ГИС также прочитаны публичные страницы с зависимостями. Полные мобильные сценарии и сетевые реестры кандидатов не проверены. Для банков сетевые адреса не исследовались.

## Ограничения и обновление

- Точечные DNS-снимки могут устаревать и различаться по региону/провайдеру. DNS через VPN способен выбрать другой CDN. Списки доменов в ресурсе описывают наблюдения, не работают как wildcard-правила.
- `2a03:720::173:2/128` Wildberries — только прежний наблюдаемый адрес сайта. Не расширять его до всего `/32`.
- Не исключаются все сети России, ASN целиком, Yandex Cloud целиком или публичный DNS Яндекса `77.88.8.8`. DNS продолжает идти через VPN.
- Натуральные сценарии входа, звонков MAX, корзины Ozon, региональных CDN, IPv6/NAT64 требуют проверки на iPhone. Неизвестные адреса остаются на прежнем маршруте.

1. Воспроизвести конкретный сбой на iPhone; отдельно проверить маршрут и распознавание VPN сервисом.
2. Найти фактические назначения без TLS MITM и записи пользовательского содержимого.
3. Сопоставить A/AAAA с каталогом, в том числе при DNS через VPN.
4. Проверить отсутствующие адреса в RIPE RDAP и RIPEstat. Общая сеть хостинга или чужой CDN не получают исключение целиком; для подтверждённого назначения допустим точечный маршрут с явно указанным ограничением.
5. Обновить ресурс, `catalogVersion`, `reviewedAt`, источники, DNS-снимок и эту записку. Не удалять запись из-за одного временного DNS-отказа.
6. Выполнить `make test`, `make strings-check`, `make release-check`; проверить каждую группу отдельно и все вместе по [сценариям устройства](DEVICE-TESTING.md#проверка-исключений-российских-сервисов).

Клиент не загружает список из сети и не обновляет его фоном. Изменения доставляются новой сборкой. `reviewedAt` — дата исследования, а не обещание срока действия адресов.
