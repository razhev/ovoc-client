# personal-ios-client

Минимальный нативный iOS-клиент для личного сервера **AmneziaVPN** (протокол **OpenVPN over Cloak**).
Для установки себе и нескольким родственникам через **TestFlight**. Не для публикации в App Store (пока).

> ⚠️ Ранняя стадия: сейчас в репозитории только план. Кода приложения ещё нет.

## Что где

- **[PLAN.md](PLAN.md)** — полный план разработки: архитектура, структура проекта, этапы (M0–M6) с проверками, риски и запасные планы. Написан подробно, для новичка в iOS.
- **[IMPLEMENTATION_PROMPT.md](IMPLEMENTATION_PROMPT.md)** — самодостаточный промпт для агента, который будет детально планировать (а затем вести) имплементацию. Содержит выжимку всего исследования: зафиксированные решения, формат ключа `vpn://`, ловушки, ссылки на эталонные исходники. Использовать с любой машины: открыть Claude Code в корне репозитория и вставить содержимое.

## Коротко о подходе

- Нативное приложение SwiftUI + одно сетевое расширение `NEPacketTunnelProvider`.
- Не пишем VPN с нуля и не форкаем приложение Amnezia (оно на Qt). Переиспользуем готовый бинарный компонент `OpenVPNAdapter.framework` от Amnezia, где OpenVPN и Cloak уже собраны вместе.
- Ключ подключения — тот же формат `vpn://…`, что экспортирует Amnezia; приложение умеет его импортировать.

## Требования (см. PLAN.md → «Что понадобится»)

- Mac с Xcode 26+
- Платный аккаунт Apple Developer ($99/год) — обязателен для VPN-расширений
- Физический iPhone для разработки (в симуляторе VPN не работает)

## Лицензионная заметка

Проект линкует `OpenVPNAdapter` / `OpenVPN3` (AGPL-3.0). Для личной раздачи через TestFlight обязательств не возникает; исходники предоставляются по запросу.
