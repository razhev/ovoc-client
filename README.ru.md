# OVoC Client

[English](README.md) · Русский

Небольшое нативное приложение для iPhone, которое подключает телефон к вашему собственному
серверу OpenVPN over Cloak — например, поднятому через [AmneziaVPN](https://amnezia.org).
У приложения нет своих серверов, учётных записей и аналитики. Вы добавляете ключ, оно даёт
кнопку «Подключить».

Cloak заворачивает трафик OpenVPN в обычную с виду HTTPS-сессию, поэтому такое соединение
трудно отличить от визита на обычный сайт.

## Что умеет

- Импортирует ключ Amnezia `vpn://…` — вставкой или из файла. Ключ остаётся на телефоне,
  внутри VPN-конфигурации iOS.
- Подключается и отключается одной кнопкой и объясняет каждое состояние простыми словами.
- Умеет пускать выбранные российские сервисы (банки, маркетплейсы, госпорталы) мимо туннеля.
  Все исключения выключены, пока вы их не включите.
- Показывает лог туннеля на отдельном экране и делится им в одно касание.
- Интерфейс — на русском и английском.

## Установка

Приложение раздаётся через TestFlight: [присоединиться к бете](https://testflight.apple.com/join/KMXkHFyz).
Нужен iPhone с iOS 16 или новее и приложение TestFlight. Текущая сборка — 0.1.0 (15)
от 2026-10-17; что менялось от сборки к сборке — в [CHANGELOG.md](CHANGELOG.md).

В App Store приложения нет. Правило 5.4 Apple допускает VPN-приложения только от организаций,
а российская витрина удаляет такие клиенты по требованию.

Ещё нужен сервер. Подойдёт любой сервер OpenVPN over Cloak; проще всего — свой AmneziaVPN
и ключ, экспортированный для протокола «OpenVPN over Cloak».

## Сборка из исходников

Понадобятся Mac с Xcode 26, [XcodeGen](https://github.com/yonaskolb/XcodeGen), Go (нужную
версию 1.22.2 сборка закрепляет сама) и аккаунт Apple Developer — ради entitlement
Network Extension. В симуляторе VPN не работает, нужен iPhone по кабелю.

```bash
make framework   # собрать OpenVPNAdapter и Cloak из исходников с патчами проекта
make test        # юнит-тесты на Mac
make install     # подписанная сборка на подключённый iPhone
```

Полный список команд, устройство проекта и отладка на устройстве — в
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Как устроено

SwiftUI-приложение и одно расширение Network Extension. В расширении работает форк
OpenVPNAdapter от Amnezia с Cloak, скомпилированным внутрь как транспорт. Фреймворк
собирается здесь из исходников с несколькими патчами: готовый бинарь не записывал метку
подлинности GCM, и сервер отбрасывал каждый пакет.

Разбор ключа живёт в локальном Swift-пакете `ConfigKit`. Приложение превращает ключ в готовый
профиль OpenVPN и передаёт его расширению через VPN-конфигурацию; само расширение ничего
не разбирает.

## Обратная связь

Если что-то не подключается — заведите [issue](https://github.com/razhev/ovoc-client/issues)
и приложите файлы с экрана «Логи». В них есть адрес сервера, но никогда нет ключа; адрес можно
вырезать. Правки через pull request тоже приветствуются.
