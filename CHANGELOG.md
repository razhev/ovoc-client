# Изменения

## 0.1.0 (3) — 2026-10-02

- При переподключении VPN сохраняет системные маршруты и DNS до получения новых настроек. Проверка отсутствия утечек при смене сети на физическом iPhone ещё не выполнена.
- Импорт ключа больше не падает на числах, не помещающихся в целое значение.
- Подключение Cloak и маршрут-исключение используют один IPv4. Ранее сохранённые ключи с доменом или отдельным Cloak endpoint нужно импортировать заново.
- IPv6 передаётся через VPN, если сервер выдал IPv6-настройки; иначе пакеты остаются в туннеле и отбрасываются.
- Ротация журнала сохраняет корректный UTF-8, поэтому русские сообщения остаются читаемыми.
- Проверки сборки, установки и TestFlight отклоняют framework без подтверждения сборки с текущим исправлением AEAD.
