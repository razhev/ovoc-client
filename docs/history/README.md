# История проекта

English: these are the planning documents from the time the project was private. They are kept
as a record of how decisions were made, not as current instructions; the current state is in the
[README](../../README.md), [CHANGELOG](../../CHANGELOG.md) and [DEVELOPMENT](../DEVELOPMENT.md).

Документы времён, когда репозиторий был закрытым. Они сохранены как запись того, как
принимались решения, а не как действующие инструкции. Текущее состояние — в
[README.ru.md](../../README.ru.md), [CHANGELOG.md](../../CHANGELOG.md) и
[DEVELOPMENT.md](../DEVELOPMENT.md).

- [PLAN.md](PLAN.md) — исходный план проекта с пометками «Как вышло».
- [IMPLEMENTATION_PROMPT.md](IMPLEMENTATION_PROMPT.md) — промпт, с которого агент начинал
  планирование.
- [IMPLEMENTATION.md](IMPLEMENTATION.md) — детальный план имплементации по этапам M0–M6.

Что учитывать при чтении:

- До 2026-11-04 репозиторий назывался `razhev/personal-ios-client` и был закрытым. Номера pull
  request в этих документах относятся к нему, а не к открытому `razhev/ovoc-client`.
- При открытии репозитория адреса авторов в истории заменены на noreply, поэтому у всех коммитов
  новые хеши. Хеши в документах уже приведены к новой истории.
- Пути к файлам указаны на момент написания; часть файлов с тех пор переехала.
